# 🌸 A Bond Beyond Words — Happy Raksha Bandhan 💖

> A beautiful, emotional, and responsive celebration website dedicated to a best friend and sister by heart on the occasion of Raksha Bandhan.

---

## ✨ Features

- 🌟 **Cinematic Welcome Screen**: Connecting Rakhi thread animation with beating glowing hearts and heartfelt quotes.
- 🎶 **Soft Ambient Instrumental Music**: Generative soothing Indian flute & acoustic raga ambient music with equalizer controls.
- 💌 **3D Origami Envelope Letter**: Interactive wax-sealed envelope that opens to reveal a handwritten Hindi/English letter.
- 📸 **Polaroid Scrapbook Gallery**: 8 nostalgic memories with washi tape trims, fullscreen HD lightbox, and live custom photo uploader.
- 🤝 **My Promises to You**: 5 sacred sibling vows with interactive "Pinky Promise Seal" stamps.
- 💬 **Things I Never Say Enough**: 5 interactive 3D flip heart cards with heartfelt gratitude.
- 🎁 **Surprise Celebration**: Confetti cannons, falling flower petals, 3D animated Rakhi, and an Official Sisterhood Certificate.
- 💳 **Lifetime Sibling VIP Privilege Pass & Vouchers**: Digital holographic pass and 4 redeemable sisterhood coupons.
- 🌙 **Starry Night Sky Finale**: Glowing crescent moon, floating sky lanterns, and interactive "Send a Virtual Hug 🤗" flying hearts button.
- ⚙️ **Live Personalizer**: Customize her name, your name, and message in real-time with LocalStorage persistence.

## 🛠️ Tech Stack

- **HTML5 & CSS3** with Glassmorphism, 3D CSS Transforms, and Scrapbook aesthetics
- **Tailwind CSS** (via CDN)
- **Vanilla JavaScript (ES6+)**
- **Web Audio API** for synthesized acoustic ambience & sound effects
- **HTML5 Canvas** for dynamic rose and marigold petal physics
- **Canvas-Confetti** & **Lucide Icons**

---

## 💻 Local Development

1. Clone this repository:
   ```bash
   git clone https://github.com/Sourabh123-atl/Rakhi-spacial-.git
   cd Rakhi-spacial-
   ```
2. Open `index.html` in any modern web browser or start a local server:
   ```bash
   python -m http.server 3000
   ```
3. Open `http://localhost:3000` in your browser.
